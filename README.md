# Haze Royale

A non-violent 2D/3D battle royale set on a Malaysian island, built with Flutter + Flame for the
UMPSA x HUAWEI GameCenter competition. Survive the shrinking haze with paint/water blasters, and plant
trees whose clean-air bubbles protect you inside the haze. English + Bahasa Malaysia.

Play in the browser: https://haze-royale.vercel.app

## Run it
```
flutter pub get
flutter run -d chrome          # desktop test (WASD move, mouse aim, click to fire)
flutter run                    # connected Android phone (landscape)
flutter test                   # unit, layout and 5 full simulated matches
```

## Build
```
flutter build apk --release --split-per-abi   # Android (needs Android Studio / SDK)
flutter build web --release                   # web
python tool/package.py                        # upload-ready zips in dist/ (each < 100 MB)
```

## Where things are
- `lib/game` — simulation (bots, haze zone, combat, trees) and the 3D renderer
- `assets/data/*.json` — every balance number (weapons, loot, zone timings, bots, score)
- `assets/audio` — sounds and music, generated by `tool/gen_audio.py` (no third-party audio)
- `lib/services/hms` — Huawei services behind interfaces with offline fakes (see `HMS_SETUP.md`)
- `CLAUDE.md` — full spec and project rules
